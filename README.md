# ⚜ Avroria wiki

Фэнтези-вики для мира **Аврории** — лёгкий движок на чистом PHP без зависимостей.
Страницы хранятся в виде Markdown-файлов с YAML-подобным фронтматтером, из которого
строятся **инфобоксы**.

## Возможности

| Возможность | Описание |
|---|---|
| 🧭 **PHP фронтенд** | Чистый PHP 8, без фреймворков и Composer. Маршрутизация через единую точку входа. |
| 📜 **Оформление страниц** | Фэнтези-тема: пергамент, золото, орнаменты, шрифты Cinzel + EB Garamond. |
| ⚜ **Инфобоксы** | Карточка статьи из фронтматтера с изображением и полями. Поддержка вики-ссылок `[[…]]`. |
| 🎠 **Карусель изображений** | Несколько изображений в карточке (`image: [a.jpg, b.jpg]`) — листалка со стрелками, точками и свайпом. |
| 🗂 **Коллекции** | Тематические подборки страниц (поле `collections`). |
| ✍ **Визуальный редактор** | WYSIWYG-редактор (contenteditable) с панелью инструментов и режимом исходника. |
| 🛠 **Редактор инфобоксов** | Форма для полей карточки: добавление, удаление, перестановка, выбор изображения. |
| 🧩 **Шаблоны инфобоксов** | Готовые наборы полей по типу страницы (персонаж, фракция, локация, народ, существо, артефакт). |
| 🌐 **Два языка** | Интерфейс на русском и английском с переключателем в шапке; выбор запоминается в cookie. |
| 🖼 **Окно импорта изображений** | Загрузка drag&drop, библиотека изображений, вставка в текст или карточку. |
| 🔎 Поиск | Живой поиск по названиям и содержимому. |
| 🔗 Вики-ссылки | `[[Страница]]`, `[[Страница\|текст]]`; «красные» ссылки на несозданные страницы. |

## Запуск

Нужен только PHP 8 с расширениями `gd` и `mbstring`.

```bash
php -S localhost:8000 router.php
```

Откройте <http://localhost:8000/>. Главная страница — «Белая длань».

Для Apache достаточно положить файлы в корень — маршрутизацию обеспечит `.htaccess`.

## Структура

```
index.php           единая точка входа и маршрутизация
router.php          роутер для встроенного сервера PHP
config.php          настройки и хелперы
lib/                ядро: Page, Markdown, Infobox, Collection, I18n
templates/          PHP-шаблоны (layout, view, editor, …)
api/                эндпоинты: save, upload, images, search
assets/css|js|img   фэнтези-тема и скрипты редактора
pages/              страницы вики (*.md)
images/             библиотека изображений
```

## Формат страницы

```markdown
---
image: White_Hand_symbol_black_backdrop_202606131948.jpeg
Регион: "[[Солянная пустыня]]"
Промысел: Работорговля
collections: [Фракции]
---

## История
Текст с [[вики-ссылками]] и **форматированием**.
```

Зарезервированные ключи (`image`, `title`, `collections`) управляют картинкой,
заголовком и коллекциями и не выводятся строками инфобокса.

## Маршруты

- `/` — главная страница
- `/wiki/<Название>` — просмотр страницы
- `/edit/<Название>` — редактор (визуальный + инфобокс + импорт изображений)
- `/collections` — список коллекций
- `/collection/<Название>` — страницы коллекции
- `/all` — все страницы
